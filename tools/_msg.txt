fix(ai): 解析模型输出的 JSON，不再把花括号显示给用户

用户截图显示解读栏是一整坨 JSON：verdict / headline / sections 原样渲染。

## 根因
ChartPrompt.SYSTEM_PROMPT 是给云端路径写的，里面**要求输出 JSON**。
端上模型照做，而我的 OnDeviceInterpreter 把输出当纯文本渲染 ——
PlainText.sanitize 只去 Markdown 标记，不去 JSON 结构。

## 改法：先解析，解析不了再退纯文本
1. 截取第一个 { 到最后一个 } 之间的内容（模型常加前言）
2. kotlinx.serialization 解析成 sections
3. 成功 → 结构化段落（title/body/tone）
4. 像 JSON 但解析失败 → **返回空 Flow 降级**，不把残缺 JSON 当正文
5. 纯文本 → PlainText.sanitize

## 判词仍取算法结果
模型的 JSON 里也有 verdict，但**一律用 request.facts 的 verdict 与 headline**。
吉凶是算法算的，不能让模型改。只有 sections 是模型写的。

## 用 kotlinx.serialization 而不是 org.json
org.json 在 JVM 单测里是 Android 的空壳实现（returnDefaultValues 下全部返回
null/0），测试根本测不了。kotlinx.serialization 本来就是依赖，且测试可跑。

## 单测 7 用例（OnDeviceParseTest）
标准 JSON / 带前言 / 判词取算法 / 残缺 JSON 降级 / 纯文本清洗 /
空输出 / sections 空数组
