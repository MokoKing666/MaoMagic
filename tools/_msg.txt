fix(settings): 修「只能用基础模式」的回归；引擎分四档；后端可选

## 1. 严重回归（我的责任）
`MagicSettings.engineTier` 原来没人用，默认值写的是 "RULE"。
我这次让降级链尊重它 —— 于是**所有用户被强制锁在基础模式**。

修：
- 默认值改 "AUTO"
- 存量迁移：读到 "RULE" 就改 "AUTO"。
  理由：这个字段在加 UI 之前**没有任何入口能改它**，
  所以存量 "RULE" 一定是旧默认，不可能是用户选择。

## 2. 引擎分四档，本地与云端分开
原来只有「基础模式 / 智能模式」两档，而「智能模式」实际是云端 AI ——
本地模型根本没进选项，用户也分不清数据去哪、要不要联网。

现在：自动 / 基础 / 本地模型 / 云端 AI，各带一句说明：
- 自动：优先本地，没下载用云端（若已配），再退回基础
- 基础：只用规则引擎，离线、可复现、不占存储
- 本地模型：手机自己算，完全不联网，需先下载 1.9 GB
- 云端 AI：会联网

云端字段的显隐条件从 cloudAiEnabled 改为 engineTier == "CLOUD_AI"。

## 3. 推理后端用户可选
新增「推理后端」：自动 / NPU / GPU / CPU。
手动选定时**只试那一个** —— 否则「选了 CPU 却偷偷用 GPU」，选择就不可信。

## 4. 如实标注 NPU 不可用
实测 litertlm-android 0.18.0 的 AAR 里只有 liblitertlm_jni.so，
**没有任何 NPU 运行时**；`com.google.ai.edge.litert:litert-npu` 在 Google Maven
也是 404。联发科/高通的 NPU 运行时是专有 .so，只存在于 litert-samples 的
目录里，不是 Maven 包。

所以推荐 GPU 是对的。UI 上写明原因，避免「我是天玑旗舰为什么推荐 GPU」的困惑。

## 5. 设置分区顺序
解卦引擎 / 智能解卦 / 外观 / 配色 / 数据 / 关于 —— 把最常调的放最前。
