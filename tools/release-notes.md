# 猫仙幻术 v1.1.0

新增**可选**的「智能模式」云端解卦。**默认关闭，不开启时应用完全离线。**

## 下载

**`app-release.apk`**（下方 Assets 区）　系统要求：Android 13（API 33）及以上。

---

## 这一版新增

### 🧠 智能模式（可选）

在「设置 → 解卦引擎」里可以把解卦切到云端 AI。

**默认是「基础模式」，完全离线。** 想用智能模式，需要你**自己填三样东西**：

| 项 | 说明 |
|---|---|
| 服务地址 | 任何 OpenAI 兼容接口的根地址，如 `https://api.example.com/v1` |
| API Key | 只存本机，用 Android Keystore 加密 |
| 模型名 | 如 `gpt-4o-mini` |

三者缺一，自动回到基础模式。**不预置任何服务商**，请求只发往你自己填的地址。

#### 它是怎么工作的

排盘（纳甲、六亲、世应、旬空、旺衰、变卦…）**仍然由本地确定性算法完成** ——
这部分结果一定是准的。云端 AI 只负责**论述**：把已经排好的完整卦盘交给它，
让它按六爻断法逐层推导。

提示词里明确写了「**绝对不要自己重新排盘**」，避免模型自作主张算错。

#### 失败即降级

网络断了、Key 填错了、服务商抽风了 —— 任何异常都会**自动落回基础模式**，
你永远能拿到结果，不会看到报错页。

### 🔒 隐私边界（重要，如实说明）

APK **声明了 `INTERNET` 权限**，因为智能模式需要它。

- **默认关闭时，应用不产生任何网络流量**，四大模块全部功能照常可用
- 请求内容**只有卦盘和你问的问题**，不含设备标识、位置、账号信息
- 没有账号、没有埋点、没有统计、没有广告 SDK
- 历史卦例与设置只存本机，卸载即清除
- 随时关掉开关，立刻恢复完全离线

> v1.0.0 的 README 写着「没有网络权限」，那是不准确的 —— 权限在脚手架阶段就已声明。
> 这一版把隐私说明改成了如实描述。

## 同时修正

### 八字两处事实错误（用户反馈）

- 副标题写着「大运流年」，但页面上**根本没有流年** —— 已改为「四柱 · 十神 · 大运」
- **输入口径没标**。经核实排盘用的是公历，但界面只写「年/月/日/时」，
  用户极可能误填农历导致整盘皆错。现在：
  - 卡片内明确写「请填【公历（阳历）】出生时间，不是农历」
  - 输入框标签改为「公历年」
  - 排盘结果回显「公历 1990-06-15 12时 · 农历 庚午年五月廿三」，一眼就能自检

### 卦盘可读性（用户反馈「不够易读」）

- **六亲列补上五行**：原来只显示「父母」，现在显示「父母土」。
  断卦看的就是用神受生受克，不显五行用户得在脑子里换算 —— 这是最大的可读性缺口
- **字号整体上调**：六亲/六神 13→15sp，纳甲与爻下小字 11→13sp，行高同步放大
- **六神提高对比度**：原来几乎糊在背景里；动爻所在爻的六神用强调色
- 变卦六亲同样补五行

### 其他

- **README 隐私章节**改成如实描述网络权限与智能模式的边界
- 修复梅花页调 `InterpreterChain` 时残留的 `.firstOrNull()`（链直接返回结果，不是 Flow）

## 关于准确性

术数内容**仅供传统文化研究与娱乐，不构成任何决策建议**。

- 64 卦的宫位、世应、纳甲、六亲**全部由京房八宫变爻规则算法生成**，不硬编码
- 五行生克、地支冲合三合、旬空等能用算术表达的，一律算术推导而非查表
- **156 个单元测试 + 全输入空间集成测试**（六爻 448 种盘、梅花 384 种盘、
  八字 720 组生辰、历法全年逐日）
- 基础模式的规则引擎是纯规则的：同样的卦象与日辰，永远得到同样的结论，可复现
