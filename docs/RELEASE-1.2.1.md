# v1.2.1

**这个版本只有一个重点：安装包从 30.2 MB 降到 6.5 MB（−78%）。**

功能与 v1.2.0 完全一致，没有新增也没有删减。

## 为什么小了这么多

查体积构成时发现 `isMinifyEnabled` 一直是 `false` ——
release 包里 25.9 MB 是**完全没压缩的代码**（dex 占 81%）。

打开 R8 代码压缩 + 资源裁剪后：

| | v1.2.0 | v1.2.1 |
|---|---|---|
| 安装包 | 30.2 MB | **6.5 MB** |

## 顺带的构建调整

- **只保留 arm64-v8a**：砍掉 32 位 ARM、x86、x86_64。
  本项目无自研 native 代码，这些 .so 来自依赖库且只占 0.1%，
  所以对体积几乎无影响，但能明确「这是纯 ARM64 应用」。
  → **x86 模拟器装不了，只能用 ARM64 真机或 arm64 镜像。**
- **显式声明 R8 full mode**：AGP 8.0 起本就默认开启，
  写出来是为了明确意图，防止将来 AGP 改默认值时没人注意。

## 升级建议

**建议所有 v1.2.0 用户升级。** 功能一样，包小 4.6 倍。

如果你之前因为 30 MB 犹豫没装，现在可以试试了。
