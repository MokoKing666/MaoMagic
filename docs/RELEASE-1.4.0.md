# v1.4.0

**端上 AI 解卦** —— 手机自己跑模型，不联网也能把卦说成人话。

## 这一版的核心：算归算，说归说

我们的立场没变：**卦理由算法算，AI 只负责表达。**

```
规则引擎（确定性）  →  用神是谁 / 旺衰如何 / 是否旬空 / 哪爻动
        ↓  已算定的事实，不许改
端上模型（2B）      →  把这些事实讲成人话
```

模型**不参与任何判断**。它看到的「已算定」段落，是程序的输出；
它写的每一段，都只是对既定结论的转述。

> 为什么这么较真：小模型做多步五行生克并不可靠，会给出「用神旺相」
> 而实际是「囚」这种听起来对、其实错的结论，而且编得很有说服力。
> 让它算，就是在骗用户。

## 新增

**智能解卦（本地模型）**

- 设置里四档可选：自动 / 基础 / 本地模型 / 云端 AI
  - **基础**：只用规则引擎，离线、可复现、不占存储
  - **本地模型**：手机自己算，**完全不联网**
  - **云端 AI**：把卦盘发给你填的服务，会联网
  - **自动**：优先本地，没下载就退下一档
- 六爻、梅花、八字、塔罗、小六壬 —— **全部接入**，不再是只有六爻有 AI

**推理后端可选**

自动 / NPU / GPU / CPU。手动选定后只试那一个——
「选了 CPU 却偷偷用 GPU」不会发生。

> ⚠️ **NPU 目前不可用。** `litertlm-android` 只带了 JNI 库，
> 联发科/高通的 NPU 运行时是芯片厂商的专有 `.so`，没有 Maven 包。
> 所以现在能用的加速是 GPU。这一点在设置里如实标注，不糊弄。

## 改动

- 模型下载：多线程分片（2/4/8 线程可选），断点续传，进度实时刷新
- 输出压成纯文本：模型爱写 Markdown / JSON，客户端统一清洗成能读的段落
- 设置分区重排：解卦引擎 / 智能解卦 放到最前
- 修「只能用基础模式」的回归（`engineTier` 旧默认值把用户锁死了）
- 移除已不再使用的 MediaPipe 运行时：包体从 54 MB 降到 28.7 MB

## 已知限制

- 模型约 1.9 GB，需单独下载（不打包进 APK）
- 2B 模型在 GPU 上首字延迟数秒，属正常
- 下载还没有通知栏进度，切后台可能被系统回收

## 升级建议

建议升级。不下载模型也能正常使用——规则引擎始终兜底，
只是文字更朴素。包体 28.7 MB（含推理运行时；比上一版 6.5 MB 大的部分就是它）。
