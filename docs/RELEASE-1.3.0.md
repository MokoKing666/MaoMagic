# v1.3.0

两件事：**六爻加神煞**，**历法内核换成 Tyme**。

## 六爻：神煞

盘面下方新增神煞卡，8 个：

| 神煞 | 取法 |
|---|---|
| 驿马 / 桃花 / 华盖 / 将星 / 劫煞 / 亡神 | 日支 → 三合局 → 十二长生 |
| 禄神、阳干羊刃 | 日干查 |

每个神煞标明落在第几爻；卦中无该地支则标「卦中无」——
知道「驿马在寅但卦里没寅」本身有信息，藏起来反而像没算。

**神煞只作参考，不参与断卦推理。** 加进规则引擎会让结论不可解释。

> 阴干羊刃没做：有「无刃」与「禄前一位」两说，取其一都可能与你的所学不符。
> 天乙贵人也没做：甲式「甲戊庚牛羊」与乙式「甲戊兼牛羊」两套，差别在庚辛两干。

## 历法内核：lunar → Tyme

换成同作者的 [tyme4kt](https://github.com/6tail/tyme4kt)（Kotlin 重写版）。

**结果一字未变**——迁移前先做了逐日对拍：

- 日干支、节气、农历：**730 天逐日一致**
- 宜忌、值星、宿、黄黑道、吉凶神：**730 天逐日一致**
- 十神、藏干、地势（四柱）：**730 天逐日一致**

Tyme 缺的四组数据自己实现了（冲、煞、彭祖百忌、五神方位、宿吉凶、农历月名日名），
同样拿 lunar 当 oracle 验到零差异。

**lunar 现在是测试专用依赖，不进 APK。**

### 顺带修好的
「节气」这一行现在显示的是**当前所处节气**（如寒露），
不再是「今天是不是节气」——后者一年只有 24 天有值，盘面上大部分时候是空的。
