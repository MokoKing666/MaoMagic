# 起卦取数规则

> 本文档是本项目所有起卦算法的**唯一权威定义**。
> 代码中的取数常量必须与本文一致；如需变更，请先提 Issue 讨论并附流派依据。

不同流派对同一套起卦法存在取数差异。本项目选定一套规则并集中定义，**不追求「唯一正确」，只保证「明确一致」**。

---

## 0. 全局位序约定

| 概念 | 约定 |
|---|---|
| 爻位 | `1..6` = 初、二、三、四、五、上 |
| 卦编码 `code` | 6 bit 整数，**初爻为最低位**（`bit0`=初 … `bit5`=上） |
| 下卦（内卦） | `code and 0b111` |
| 上卦（外卦） | `(code shr 3) and 0b111` |
| 余数为 0 的处理 | 取模后余 0 一律取**模数本身**（除 8 余 0 取 8，除 6 余 0 取 6） |

## 3. 铜钱摇卦（六爻正统法）

### 摇法
三枚铜钱合于掌中摇动掷出，共掷 **6 次**。

### 记数
| 面 | 记数 |
|---|---|
| 正面（有字面） | 3 |
| 反面（背面） | 2 |

### 成爻
三枚之和：

| 和值 | 爻象 | 名称 | 是否动爻 |
|---|---|---|---|
| 6 | 阴爻（⚋） | 老阴 | ✅ 动（阴变阳） |
| 7 | 阳爻（⚊） | 少阳 | ❌ |
| 8 | 阴爻（⚋） | 少阴 | ❌ |
| 9 | 阳爻（⚊） | 老阳 | ✅ 动（阳变阴） |

### 记录顺序
**第一次掷出者为初爻（最下），第六次为上爻（最上）** —— 自下而上。

### 动爻
老阴（6）与老阳（9）所在爻位即为动爻。动爻阴阳互变，得到变卦。

## 4. 时间起卦

采用《梅花易数》原文取数法（六爻模块借用同一套规则，UI 中已标注）。

### 输入
起卦时刻对应的**农历**：年支、月、日、时支。

| 项 | 取值 |
|---|---|
| 年支序 | 见 §2（子=1 … 亥=12），**按农历年支** |
| 月数 | 农历月份数，正月=1 … 十二月=12 |
| 日数 | 农历日数，初一=1 … 三十=30 |
| 时支序 | 见 §2，按起卦时刻所在时辰（子时=23:00–00:59） |

### 计算

```
上卦数 = (年支序 + 月数 + 日数) mod 8          余 0 取 8
下卦数 = (年支序 + 月数 + 日数 + 时支序) mod 8   余 0 取 8
动爻   = (年支序 + 月数 + 日数 + 时支序) mod 6   余 0 取 6
```

### 拼装
```
code = (先天八卦数→bits(上卦数) shl 3) or 先天八卦数→bits(下卦数)
```

### 说明
- 时间起卦法源自《梅花易数》，严格来说属梅花体系；六爻传统仅用铜钱摇卦。本项目在六爻模块中同时提供，UI 上标注为「现代派/便捷起卦」，供用户自选。
- 年支序**不**取年数，只取地支序（与部分流派的「年数取地支序」一致）。

## 5. 数字起卦

### 两数法（主用）

```
上卦数 = 数1 mod 8    余 0 取 8
下卦数 = 数2 mod 8    余 0 取 8
动爻   = (数1 + 数2) mod 6   余 0 取 6
```

### 一数法

若用户只提供 1 个数：

```
上卦数 = 数 mod 8                     余 0 取 8
下卦数 = (数 + 起卦时支序) mod 8       余 0 取 8
动爻   = (数 + 起卦时支序) mod 6       余 0 取 6
```

### 说明
- 两数法用于「报两个数」或「两个字的笔画数」
- 一数法需引入时支序以避免上下卦恒等；这是本项目的**明确约定**，非古籍原文

## 6. 报字起卦（梅花易数）

### 字数法
| 字数 | 取法 |
|---|---|
| 2 字 | 前 1 字笔画数取上卦，后 1 字笔画数取下卦 |
| 3 字及以上 | 前半字数取上卦，后半字数取下卦 |
| 1 字 | 按上下结构拆分笔画数；无法拆分则退回 §5 一数法 |

```
上卦数 = 前半笔画/字数 mod 8   余 0 取 8
下卦数 = 后半笔画/字数 mod 8   余 0 取 8
动爻   = (前半 + 后半) mod 6   余 0 取 6
```

### 笔画数标准
统一采用**简体字规范笔画数**（GB13000 / 现代汉语通用字笔顺规范）。
若用户要求繁体，则按其输入字符的 Unicode 码位查表，本项目**不内置繁体笔画库**，需用户自行输入笔画数。

> ⚠️ 笔画数是最易产生分歧的一环（简体/繁体、新旧字形、部首笔画计法）。本项目选择「用户直接输入笔画数」的交互方式，避免内置字库带来的争议。

## 7. 手动指定

用户直接点选 6 爻的阴阳与动爻。

- 阴阳：直接决定 `code`
- 动爻：用户勾选，可多选也可不选
- 此方式不涉及取数规则，用于复盘已有卦例

---

## 8. 梅花易数体用

### 定体用
- **动爻所在之卦为「用卦」，另一卦为「体卦」**
- 动爻在下卦（爻 1–3）→ 下卦为用、上卦为体
- 动爻在上卦（爻 4–6）→ 上卦为用、下卦为体

### 五行生克关系（吉凶倾向）

| 关系 | 含义 | 倾向 |
|---|---|---|
| 用生体 | 用卦生体卦 | 吉 |
| 体用比和 | 同五行 | 吉 |
| 体克用 | 体卦克用卦 | 吉（但费力） |
| 体生用 | 体卦生用卦 | 凶（耗泄） |
| 用克体 | 用卦克体卦 | 凶 |

### 互卦
```
互下卦 = 本卦爻 2、3、4
互上卦 = 本卦爻 3、4、5
互卦 code = (互上卦 bits shl 3) or 互下卦 bits
```

### 变卦
动爻阴阳互变后所得之卦。

## 9. 六爻装卦规则（简表）

详细算法见 `core/hexagram` 模块源码与 `docs/ARCHITECTURE.md`。

| 项 | 规则 |
|---|---|
| 宫位 | 京房八宫，每宫八卦：本宫、一世、二世、三世、四世、五世、游魂、归魂 |
| 世爻 | 本宫=6、一世=1、二世=2、三世=3、四世=4、五世=5、游魂=4、归魂=3 |
| 应爻 | `((世爻 - 1 + 3) mod 6) + 1`（世应相隔三位） |
| 纳甲 | 下卦取该卦爻 1–3，上卦取该卦爻 4–6 |
| 六亲 | 以**宫五行**为「我」：同我=兄弟、我生=子孙、我克=妻财、克我=官鬼、生我=父母 |
| 六神 | 按**日干**起：甲乙起青龙、丙丁起朱雀、戊起勾陈、己起腾蛇、庚辛起白虎、壬癸起玄武；初爻向上顺排 |
| 空亡 | 按**日柱**旬空 |
| 伏神 | 本卦缺失的六亲，取本宫卦（纯卦）中该六亲所在爻位的干支，伏于本卦**同爻位**之下 |
| 变卦六亲 | 以**变卦自身所属宫**的五行重新计算 |

## 10. 变更流程

任何取数规则的修改必须：

1. 先提 Issue，说明**流派来源与古籍依据**
2. 在本文档更新对应章节，并注明变更理由
3. 同步更新 `core:hexagram` 中的常量与黄金测试

**不接受**无依据的规则变更。
