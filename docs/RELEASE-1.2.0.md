# v1.2.0

六爻从「能排盘」变成「能摇、能听、能回看」。83 个提交。

## 六爻：起卦

- **铜钱一爻一摇**：原来一次摇出六爻，现在一爻一摇、六摇成卦。
  按钮跟着爻位走：摇初爻 → 摇二爻 → … → 六爻已齐
- **三枚方孔钱**：Canvas 画的暗金方孔钱，字面四道纹、背面光素，正反一眼可分
- **翻转动画**：每次摇出一爻，三枚同时翻两圈
- **摇一摇**：加速度计判定，晃手机也能摇（阈值 24 m/s² + 连续 2 帧，防磕碰误触）
- **音效**：合成的三枚铜钱落桌声（非采样，无版权问题）

## 六爻：盘面

- **按通行排盘重排**：六神 | 六亲+地支+五行 | 干支·世应 | 爻符 | 动爻 | 爻符 | 变卦六亲
  - 世应压进行内（「甲子 · 世」），不再独立成列
  - 动爻标 ○ / ×
  - 变卦侧补全六亲、地支、五行
- **顶部信息表**：事项 / 月建 / 节气 / 日辰·旬空 / 卦式
- **节气行**：显示当前所处节气（如「寒露」），解释月建为何是这一支

## 六爻：卦例

- **可点开查看**：用记录时间还原当时的日课，**不是今天**
  （六爻断卦靠日辰定旺衰，用今日日辰重算旧卦结论就错了）
- **顶部标识**：「正在查看历史卦例 / 日课按记录时间还原，不是今天」+ 返回当前
- **导出 / 导入**：JSON 格式，系统文件选择器，换手机不再丢卦例
- **两段式删除**：单击查看，行尾「删除」→「确认删除」，不会误删

## 八字

- **支持按农历填生辰**：闰月填负数（如闰五月填 −5），排盘前自动换算

## 设置

- **明暗模式**：跟随系统 / 浅色 / 深色
- **恢复默认设置**：一键还原外观与配色（不动云端配置、引擎档位、卦例）

## 修复

- 卦盘闪退（`Modifier.weight` 传了 0f，组合阶段抛异常）
- 卦例列表单击即删除、无二次确认

  需要先定口径。见 `docs/神煞取法.md`

- 六爻盘面的「变卦」在无动爻时为空，属正常
